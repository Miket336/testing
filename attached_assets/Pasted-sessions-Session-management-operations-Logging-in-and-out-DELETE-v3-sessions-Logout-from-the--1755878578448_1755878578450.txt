sessions
Session management operations - Logging in and out



DELETE
/v3/sessions/
Logout from the current session.

POST
/v3/sessions/
Login using this route.

POST
/v3/sessions/verify/
Verify login step for multi factor authentication (MFA).
accounts
Account information



GET
/v3/accounts/
Retrieve account information.

events
Events listed in the exchange



GET
/v3/events/
Retrieve events that are available on Smarkets to bet on.

GET
/v3/events/{event_ids}/states/
Retrieve the current states for events by id.
competitors
Competitors for each event



GET
/v3/events/{event_ids}/competitors/
Retrieve competitors of a set of events.
markets
Markets for each event



GET
/v3/events/{event_ids}/markets/
Retrieve markets by event ids. This should be done after getting events.

GET
/v3/events/{event_ids}/markets_count/
Retrieve markets_count by event ids. This should be done after getting events.
contracts
Contracts for each market



GET
/v3/markets/{market_ids}/contracts/
Retrieve contracts by a set of market ids.
volumes
Traded volumes in the exchange



GET
/v3/markets/{market_ids}/volumes/
Retrieve traded volumes by market ids.

prices
Quotes and execution information



GET
/v3/markets/{market_ids}/last_executed_prices/
Retrieve the last executed price and timestamp for each contract in the market ids provided.


GET
/v3/markets/{market_ids}/quotes/
Get the current prices from the exchange.

currencies
Currency rates



GET
/v3/currencies/{code}/
Retrieve the conversion rate for one specific currency.
orders
Placing and fetching exchange orders



DELETE
/v3/orders/
Cancel all orders.


GET
/v3/orders/
Retrieve current orders on Smarkets, these include open and recently settled orders.


POST
/v3/orders/
Place orders on the exchange.


GET
/v3/orders/fullcover/
Get all fullcover orders for an account.


DELETE
/v3/orders/{order_id}/
Cancel specific order.

account_activity
Statement for an account



GET
/v3/account_activity_csv/{start_datetime}/{end_datetime}/
Return the account activity between the two specified datetimes as a gzipped CSV.


GET
/v3/accounts/activity/
Retrieve statement information for your account.
